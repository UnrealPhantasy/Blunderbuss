# Opening book — one line per opening, UCI moves from the start position.
#
# The table is built by replaying these, recording (position -> next move). Two lines that reach
# the same position therefore feed the same key, which is how transpositions cost nothing.
#
# Stage one is hand-written on purpose: it exercises the mechanism without the data pipeline,
# which is the expensive half and buys the least while the measurement protocol starts every game
# from an offbeat first move. See issue #71.

# --- 1.e4 e5

e2e4 e7e5 g1f3 b8c6 d2d4 e5d4 f3d4 g8f6      # Scotch
e2e4 e7e5 g1f3 g8f6 f3e5 d7d6 e5f3 f6e4      # Petrov
